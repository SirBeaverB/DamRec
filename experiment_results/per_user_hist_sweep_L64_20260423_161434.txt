====================================================================================================
Per-User History Length Sweep on ml-1m  (non-streaming, leave-one-out)
====================================================================================================

[实验情景]
  对每个 N ∈ {10, 50, 100} 创建 ml-1m-perN 子集：每 user 按 timestamp 保留 last N 条交互。
  RecBole 标准 leave-one-out 划分（每 user 最后 1 个 = test，倒数第 2 = valid，其余 = train）。
  五模型简化为 3 个对照：GDN（SGD 基线）/ Adam=DamRec（逐维度 Adam）/ Fro=FroRec（F-Adam）。

[研究问题]
  per-user 历史长度变短时，Adam-family 相对 SGD 的优势 Δ 是否随 N 减小而单调放大？
  若成立 → 主图：横轴 N，纵轴 Δ%(Adam-GDN) / Δ%(Fro-GDN)，证实 sample-efficient claim。

[超参数]
  N levels       = [10, 50, 100]
  models         = ['GDN', 'Adam', 'Fro']
  max_seq_len L  = 64  (固定，CHUNK_SIZE=16 兼容；N=100 时 L 绑定取 last 64)
  epochs         = 150  (受 stopping_step=10 早停控制)
  random seed    = 2020  (RecBole default; 单 seed 单次运行)

[判读]
  TEST 表格里 Δ(Adam-GDN) 和 Δ(Fro-GDN) 是关键。预期：
    N=100: Δ ≈ +3% ~ +5%   (per-user 数据较多，SGD 已够用)
    N=50 : Δ ≈ +10% ~ +15%
    N=10 : Δ ≈ +20% ~ +40% (per-user 极稀疏，Adam 优势放大)
  若三档单调上升 → sample-efficient 假设成立，可作论文主图。
  若三档随机起伏 → 单 seed 噪声主导，需补 multi-seed。
