==========================================================================================
Per-Model Pretrain + Streaming T2T on ml-1m (80/20 temporal split)
==========================================================================================

[实验情景]
  ml-1m 按 timestamp 全局排序后切 80/20：前 80% 作 pretrain，后 20% 作 streaming T2T。
  每个模型独立在 pretrain 上跑完整预训练（非嫁接，所有独有参数都训），
  预训练结束后 replay 一次 pretrain 导出 per-user 内部状态 (S, M, V) 到 user_states.pt，
  再进入 T2T 阶段：模型加载 ckp + user_states，按真实时间顺序处理后 20% 交互。

[评估协议] Prequential streaming (Gama et al., 2009)
  每个 user 的 t2t 尾部 10% 交互被标为 test 点。流式迭代时：
    1) 到达 test 点先 full_sort_predict → 记录 Recall/NDCG/MRR
    2) 整个 batch（含 test 点）参与 loss.backward() → 模拟在线反馈
    3) 交互加入 user_history；模型的 per-user S/M/V 持续演化，不重置
  每 user 约 3 个 test 点，总 test 点 ~18K，所以 Recall@10 绝对值约在 0.01 量级。

[模型对照]
  GDN  = Gated Delta Net（基线，前向 ≡ 在线 SGD）
  Mo   = MoRec（动量式前向更新）
  Nest = NestRec（Nesterov 动量）
  Adam = DamRec（Adam 式，秩一分解 V_r⊙V_k^T）
  Fro  = FroRec（F-Adam，V 降维为 Frobenius 标量）

[超参数]
  max_seq_len L         = 64
  pretrain_epochs       = 150  (实际受 stopping_step=10 早停控制)
  pretrain_batch_size   = 2048 (default), lr = 1e-3 (yaml default)
  t2t_lr                = 0.0001  (流式阶段)
  t2t_epochs            = 1 (prequential 单次 pass)
  t2t_test_ratio        = 0.1  (每 user 尾部 10% 为 test)
  random seed           = 2020  (RecBole default; 单 seed 单次运行)
